# My Map App 3

Android Google Maps app.

Features:
- Google Maps
- Current-location permission
- Long-press map to add a marker
- Enter a place name and save a marker at the map center
- GitHub Actions builds a debug APK

## Google Maps API key
Replace YOUR_GOOGLE_MAPS_API_KEY in:
app/src/main/res/values/strings.xml

Then run the GitHub Actions workflow to build the APK.
